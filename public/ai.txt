# ajew.org AI and crawler access

For reader pages, do not rely on JavaScript navigation. Use the static plain text endpoints.

Patterns:
- Section HTML: https://ajew.org/reader-plain/<book>/<part>/<section>/
- Section TXT: https://ajew.org/reader-plain/<book>/<part>/<section>/index.txt
- Section Markdown: https://ajew.org/reader-plain/<book>/<part>/<section>/index.md
- Section JSON: https://ajew.org/reader-plain/<book>/<part>/<section>/index.json
- Complete work TXT: https://ajew.org/reader-plain/<book>/full.txt
- Complete work Markdown: https://ajew.org/reader-plain/<book>/full.md
- Full catalog: https://ajew.org/reader-plain/index.json
- Plain sitemap: https://ajew.org/reader-plain/sitemap.txt
- XML sitemap: https://ajew.org/reader-plain/sitemap.xml

Example Adir BaMurom:
- Human reader: https://ajew.org/reader/ramchal-adir-bamuroam/1/1/
- Complete static text: https://ajew.org/reader-plain/ramchal-adir-bamuroam/full.txt

If looking for a quoted phrase, search the plain endpoints and site search. Some paragraphs quoted as from Adir BaMurom may appear inside Likutay Nanach commentary pages that cite Adir, e.g. https://ajew.org/reader-plain/likutay-nanach/full.txt .
