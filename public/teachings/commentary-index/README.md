# Commentary Index for Nach Teachings

This directory serves as an index for commentaries on the teachings of Rebbe Nachman of Breslov.

## Available Commentaries

### Primary Commentaries
- **rimzay-maaseyos** — Commentary on the Tales (Stories) of Rebbe Nachman
- **likutay-nanach-volume-4** — Commentary from Likutay Nanach, Volume 4

### Books with Commentary Structure

#### Likutay Moharan
- Each Torah lecture (e.g., `likutay-moharan-torah-1`, `...-torah-2`, etc.) has its own commentary directory
- Intro and Prefaces also have dedicated commentaries

#### Likutay Tefilos
- Each prayer lecture has its own commentary

#### Likutay Eitzos
- Each advice section has its own commentary

#### Chayey Moharan
- Biography and teachings of Rebbe Nachman

#### Stories (Tales)
- `stories/tale-1`, `stories/tale-2` — Individual tale commentaries

#### Other Works
- `blossoms-of-the-stream`
- `af-af`
- `limudim`

## Adding New Commentaries

1. Create a directory under the relevant book: `teachings/<book>/commentary/`
2. Add commentary files (Markdown or HTML)
3. Update this index
