# Glossary

## Transliteration Conventions

This glossary uses the following transliteration rules for Hebrew vowel points (nikkud):

- **cheereek** (חִירֵק) → `ee` (not “i”)  
- **tzairay** (צֵירַי) → `ei` for common words; use true phonetics for uncommon words to aid pronunciation  
- **eye** sound (אֵי) → `ai` (kept for compatibility)  
- **shuruk** (שׁוּרוּק) → `oo` (not “u”), except at word‑start/end where `u` is acceptable  

> These rules prioritize readability and phonetic clarity over conventional spelling. When in doubt, favor phonetics for less‑common terms.
