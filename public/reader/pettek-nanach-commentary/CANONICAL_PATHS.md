## Schema

Every commentary file:

    { id, book, part, torah, title, hebrewTitle, author: "Pettek Nanach",
      segments: [
        { index, relatedSegment, layers: {
            beginner:     { en, he },
            intermediate: { en, he },
            scholarly:    { en, he } } } ] }

Conventions used by the corpus:

- `beginner.he` — typically empty (English-only beginner layer).
- `scholarly.en` — typically empty (Hebrew-only scholarly layer).
- A segment whose `beginner.en` is just an ois letter (e.g. `**"ד."**`) is an
  intentional section heading, not a missing piece.
- Higher-numbered torahs (N >= 97) are generally shorter and were generated by
  the `write_t*.py` scripts in `_source-archive\pettek-nanach-patches\`.
